KB GROUP FOR FURNITURE — WEBSITE FILES
=====================================

FILES
- index.html       Homepage, categories, contact details and feedback form
- salon.html       Salon / living room gallery
- kitchen.html     Kitchen gallery
- bedroom.html     Bedroom gallery
- dining.html      Dining room gallery
- style.css        Responsive design, animations, colors and layout
- script.js        Category item arrays, navigation and feedback demo

HOW TO PREVIEW
1. Keep all HTML files, style.css and script.js in the same folder.
2. Open index.html in a modern browser.
3. An internet connection is required for the sample Unsplash furniture photos.
   You can replace the image URLs in script.js with local image paths, such as:
   images/salon-sofa.jpg

HOW TO EDIT THE FURNITURE
Open script.js. Near the top, find salonItems, kitchenItems, bedroomItems,
and diningItems. Each entry has:
  image:       path or URL for the image
  title:       product title
  description: short description

CONTACT DETAILS
The phone and WhatsApp numbers on index.html are placeholders. Replace
+20 100 000 0000 and the corresponding wa.me link with your real business
number. Update Facebook and Instagram links too.

FEEDBACK FORM NOTE
The form currently validates the fields and displays a demo confirmation.
It does not email, upload, or save feedback. To receive real submissions,
connect it to a backend or a form service.

PUBLISHING
You can upload all files to a static host such as GitHub Pages or Netlify.
Do not rename style.css or script.js unless you also update the links in
the HTML pages.
